# Инструкции для LLM-агента, работающего над данным проектом

Ты - Python-разработчик, с большим опытом разработки ПО для криптовалютных бирж и бирж в целом, который работает над проектом [fundingbot](https://github.com/alexander-klimov/fundingbot).
Ты должен помочь мне с реализацией клиента для биржи Kraken.

1) Тебе нельзя читать файл `.env`.

2) fundingbot-sdk - это библиотечный код, который я не могу менять (если совсем нужно что-то изменить, то я попрошу команду, которая разрабатывает эту библиотеку.
 
3) BitgetClient - это рабочая реализация клиента криптобиржи Bitget. Эту реализацию я собираюсь использовать, как пример реализации CcxtClient.

4) Моя задача реализовать клиента для Futures Kraken API.
Я начал с того, что скопировал класс BitgetClient в KrakenClient (и нексколько соседних классов),
5) теперь я хочу его адаптировать так, чтобы проходили тесты.

5) В качестве оболочки командной строки используй PowerShell.

6) При работе с Python активируй уже созданное виртуальное окружение в папке `./venv`.

7) Знания по особенностям биржи Kraken можно прочитать в файле [KRAKEN_FUTURES_API_RESEARCH.md](docs/KRAKEN_API_RESEARCH.md)

8) Перед увыполнением тестов нужно убедиться, установлена ли переменная окружения KRAKEN_API_KEY. Если нет, то нужно применить скрипт `scripts\ApplyDotEnv.ps1`.
